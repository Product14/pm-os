# context/: reviewed shared knowledge

Every PM's Claude reads this. Nothing is written here by hand.

- **Adding knowledge:** use `/pm-os:capture`. It writes a candidate to `queue/`; the reviewer checks it against `reviewer/RUBRIC.md` and merges it here, or holds or rejects it.
- **Wrong or stale entry:** use `/pm-os:veto`. Never edit or delete a stable entry directly.
- **Lessons** (`lessons/<target>/`) come from PM gate feedback through the PRD retro; **persona observations** (`personas/<role>/observations/`) come from `/pm-os:persona-refresh`. Both go through `queue/`.
- **Persona cores** (`personas/<role>/core.md`) change only by the PM OS owner, in a reviewed PR that keeps the persona-fidelity evals passing. `watchlist.md` files are written by persona refresh.
- `INDEX.md` is generated by `node scripts/index.mjs`. Never edit it.
- Before any metric or data query, read the trap and metric lines in `INDEX.md` and load the entries that apply.
