Run it locally

The repo lives at ~/Documents/claude-code/apps/pm-os. Nothing is published, so everything below runs on your laptop.

Option A: load the plugin for one session (best while testing)

Picks up edits immediately. Nothing is installed.

cd ~/Documents/claude-code/apps/pm-os
claude --plugin-dir ./plugin

Option B: install it like a teammate would

Claude copies the plugin into its cache. After editing the plugin, run the update line, then restart Claude Code.

claude plugin marketplace add ~/Documents/claude-code/apps/pm-os
claude plugin install pm-os@spyne-pm-os
# after edits:
claude plugin marketplace update spyne-pm-os

Run the reviewer pipeline

Repair, then context review, then skill review. The source roots let the reviewer open your memory files and workspace to verify sources.

cd ~/Documents/claude-code/apps/pm-os
PM_OS_SOURCE_ROOTS="$HOME/.claude/projects/-Users-yash-Documents-claude-code/memory:$HOME/Documents/claude-code" \
  bash scripts/pm-os-review.sh

Known limits before you start

  • The GitHub Actions cannot run until the repo is published, so capability 20 and 21 are untested.
  • The goals sheet template link is still missing, so setup skips the goals step and records it as pending.
  • Google Sheets and Atlassian did not load in the build session. Setup will tell you if they load for you.
  • Setup looks for the repo at ~/pm-os or ~/Documents/pm-os. Yours is elsewhere, so it will ask for the path.
  • Reviewer runs cost about $0.11 per entry. The reviewer eval costs about $1.
