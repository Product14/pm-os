Get it running (no terminal)

Everything below happens inside Claude Code. When a step says "type", type it into the Claude Code prompt. When it says "ask Claude", say it in plain words and Claude runs whatever is needed.

  1. Add the plugin. In Claude Code, type /plugins (in the terminal app it is /plugin). Open the Marketplaces tab and add this folder path: ~/Documents/claude-code/apps/pm-os. Then open the Plugins tab and install pm-os.
  2. Start a new conversation so the plugin loads. You should see a line saying the PM OS is not set up yet.
  3. Type /pm-os:setup. When it asks for the repo, give it ~/Documents/claude-code/apps/pm-os.
  4. Add your keys. Type /plugins, open Installed, choose pm-os, then Configure. Fill in your Freshdesk API key and your ClickHouse user and password. Then type /reload-plugins.
  5. After you edit the PM OS, open /plugins, Marketplaces, and update spyne-pm-os so Claude picks up the change.

For the team, none of this is needed: an org Owner adds the repo once under claude.ai Organization settings, Plugins and skills, and pm-os appears for every PM.

Known limits before you start

  • The last two capabilities need the repo published to GitHub, so they cannot be tested yet.
  • The goals sheet template link is still missing, so setup skips the goals step and records it as pending.
  • Google Sheets and Atlassian did not load in the build session. Setup will tell you if they load for you.
  • Setup looks for the repo in your home folder first. Yours is elsewhere, so it will ask for the folder.
  • Until the repo is published, contributions are saved on your laptop and reviewed when you type /pm-os:reviewer run.
  • Reviewer runs cost about $0.11 per entry. The reviewer eval costs about $1.
