**Rule:** Build the live agent test as a mode of the existing demo flow for Sales and Service agents, launched from Settings > Agents > Talk to agent; never open the prospect demo itself to live rooftops.

**Why:** The judge deferred on unknown demand and P&L, and the PM overrode it on 2026-10-22: live rooftops already test through Talk to agent and those tests reach their reports and CRM, so a guided, test-flagged path on the real agent replaces an unmanaged one.

**Instead:** When a live rooftop asks to hear its agent, point it to the live agent test; until it ships, Talk to agent with the caveat that test calls appear in reports.
